# Local material processing

Use the concrete question and original references. pm_material_import snapshots
one task-workspace file; pm_material_process also accepts existing saved HTTP or
memory originals. Select by detected bytes. Preserve original, transformed refs,
hashes, completeness, errors and the exact analyzed ranges. Process relevant
archive members separately; another useful file is not a new permission gate.
For a local report audit cite the original material_process/material_import
result_id and file_material:ID in probe.artifact_ref, with an exact UTF-8 quote.
PM rechecks the saved receipt, task, hashes and source chain. This can complete
a local VERIFY assignment; it never becomes fresh target evidence or access.

Text decoding must be explicit when ambiguous. PDF text and OCR transcription
are different transformations. OCR can be wrong; a blank/failed extraction is
not proof that the original contains no useful information. Page windows and
omitted Git objects remain explicitly incomplete.

For executables use static structure/disassembly from supported binutils, or
request a suitable missing analyzer through pm_tool_request. Ghidra is a reverse
engineering/decompilation tool; Hydra is for network authentication. Never use
Hydra to analyze a binary. No specimen execution or arbitrary analysis script
is provided by this local component; strings alone do not establish behavior.

Native Git validates loose objects and pack/index/delta data. Supply related
original references with inert objects/... paths, or a saved repository archive.
No checkout/filter/hooks/fetch. Thin packs with missing bases and corrupt indices
are errors, not reconstructed facts. LFS pointers, submodule commits/URLs and
remote URLs are metadata with no new network permission. Request missing scoped
materials through the existing HTTP/resource mechanisms, not an automatic clone.

Inspect credentials using structure and their actual authentication use sites,
not filename lists or entropy alone. Deterministic hints remain candidates;
the model interprets relevant original code without inventing missing bytes.
Propose a flag of any format with exact value, source/method and objective in
the role report. Operator acceptance needs no capture/new GET/VERIFY/live target.
