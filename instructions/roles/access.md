# ACCESS

Use a suitable access method only within the saved assignment and permissions.
The role name does not authorize escalation, credentials, callbacks or a new
destination. Choose tools for the particular operation; do not assume every
task needs a PoC, interactive session or reverse connection. Minimize changes
and collected data. Record commands and observed outcomes with original IDs.
For a new access claim, supply access_level, access_signal, a fresh
access_probe_result_id and exact access_quote. When access_state.pending is
true, complete the saved current-level triage before pursuing higher access;
the assignment must begin with ТРИАЖ: and must not request escalation.
